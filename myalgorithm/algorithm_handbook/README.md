# 分类后的算法源码

这里是比赛模板和学习示例的目录。先看 [学习路线与练习](./STUDY_PLAN.md)，按「能否独立复写和解释」记录掌握情况。

每次单独编译一个文件。带输入输出的示例可直接运行；只有函数或空 main 的文件，复制需要的函数或结构体到题解中。使用 GCC 的 C++17 模式，避免把多份含 main 的源码一起链接。

## 01_basic 基础算法

- 排序：冒泡、选择、插入、快速、希尔、归并、堆排序。
- 查找：普通二分、`lower_bound`、`upper_bound`。
- [二分答案](./01_basic/binary_search_answer.cpp)：`firstTrue` 找第一个可行值，`lastTrue` 找最后一个可行值；全不可行返回 `nullopt`。
- 其他：离散化、高精度、手写堆、前缀和、差分、双指针。

建议先学习：`sort.cpp → doublesearch.cpp → prefix_difference.cpp → two_pointers.cpp`。

## 02_search 搜索与递归

- DFS 网格搜索。
- BFS 最短步数。
- 多源 BFS。
- 0-1 BFS。
- 汉诺塔递归。

选择方法：无权或单位边权用 BFS；边权只有 0 和 1 时用 0-1 BFS。走格子时如果朝向会影响下一步的费用，就要把朝向存进状态。

## 03_graph 图论

- 邻接矩阵、邻接表、链式前向星。
- Dijkstra 和堆优化 Dijkstra。
- Bellman-Ford、Floyd。
- Kahn 拓扑排序。
- 并查集。
- Kruskal、Prim 最小生成树。
- 匈牙利算法。
- 倍增 LCA。

建议顺序：图的存储 → 遍历 → 最短路 → 并查集 → 最小生成树 → LCA。

- [堆优化 Dijkstra](./03_graph/dijkstra_priority.cpp) 示例读 `n m s` 后接有向边，只允许非负边权；展示输出用 `-1` 表示不可达，提交到 OJ 前按题意改输出。可达距离需要小于 `LLONG_MAX`。
- Kahn 的示例读 `n m` 后接 `m` 条有向边。有环时 `topsort` 返回 `nullopt`。无向图的 Prim、Kruskal 支持负权，不连通返回 `nullopt`；合法总权值可能恰好等于 `-1`。
- 倍增用法：`LCA jump(tree, root);` 后调用 `jump.lca(u,v)` 或 `jump.ancestor(u,k)`。输入是一棵连通无向树，顶点从 1 编号。
- Bellman-Ford 只检测从起点可达的负环。Floyd 使用前，对角线设为 0，不可达设为源码中的 `INF`，重边取最小值；函数不标记受负环影响的点对。两者的有限距离须低于 `INF`，松弛加法也不能溢出。
- 图存储目录里的部分 DFS 按树遍历，只跳过父节点；改成一般图时要加访问标记。

## 04_dp 动态规划

- 01 背包、完全背包、多重背包、分组背包。
- 最长公共子序列。
- 编辑距离。
- 石子合并型区间 DP。

背包循环方向：01 背包容量倒序，完全背包容量正序。模板求的是「总容量不超过上限」；改成「恰好装满」时，只有 `dp[0]=0`，其余状态初始不可达。

## 05_data_structure 数据结构

- 单链表、双向链表。
- 顺序栈、动态栈、链栈。
- 顺序队列、循环队列。
- 二叉树构造和遍历。
- 单调栈、单调队列、滑动窗口。
- 树状数组、ST 表、懒标记线段树。

建议顺序：栈/队列/链表 → 单调结构 → 树状数组 → ST 表 → 线段树。

- 树状数组用法：`Fenwick bit(n);`，`bit.change(i,delta)`、`bit.rangeSum(l,r)`。线段树从 `build(1,1,n)` 开始。两者使用 1-based 闭区间。
- ST 表适合静态区间最大值、最小值或 gcd；它用两个可能重叠的区间，不能直接用于区间求和。静态区间和用前缀和。

## 练原理还是比赛复用

手写排序、指针版链表/栈/队列和二叉树建树适合练原理。比赛优先使用 `std::sort` 和 STL 容器；手写快排的固定枢轴在有序或大量重复的数据上可能退化。把模板复制到题解前，先确认输入格式、下标、数值范围和多组初始化。
