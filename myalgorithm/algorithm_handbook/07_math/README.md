# 数学算法学习

沿用本库的普通函数、数组/vector、ll 和中文注释写法。每个新增 cpp 都有可独立运行的输入输出示例。各文件是独立模板，复制到同一道题时需合并重复的 quickPower、exgcd 和 main。

## 建议顺序

1. `number_theory.cpp`：复习快速幂、埃氏筛、扩展欧几里得。
2. `xianxingshai.cpp`：线性筛和分段筛。先理解为什么每个合数只被最小质因数筛一次，再用不超过 √r 的质数标记窄区间 [l,r]。
3. `prime_factor.cpp`：试除分解、约数个数、约数枚举，理解质因数分解与约数选择的关系。
4. `euler.cpp`：从互质计数理解欧拉函数，再学习线性筛递推。
5. `inverse.cpp`：理解模意义下的除法，并区分一般模数与质数模数。
6. `combination.cpp`：用阶乘和逆阶乘回答组合计数查询。
7. `matrix_power.cpp`：把斐波那契递推写成矩阵，再推广到其他固定线性递推。

## 示例与边界

| 文件 | 输入 | 预期输出或含义 | 条件 |
| --- | --- | --- | --- |
| xianxingshai.cpp | `10 20` | `11 13 17 19` | 0 ≤ l ≤ r ≤ INT_MAX；区间长度须能放进内存 |
| prime_factor.cpp | `12` | `2^2 3^1`；`6`；`1 2 3 4 6 12`（三行） | 1 到 10^12；输入 1 时首行为空、约数只有 1 |
| euler.cpp | `10` | `4`；`1 1 2 2 4 2 6 4 6 4`（两行） | 示例 n 为 1 到 10^6 |
| inverse.cpp | `3 11` | `4` | gcd(a,mod)=1 时才有逆元 |
| inverse.cpp | `6 9` | `-1` | 不存在逆元 |
| combination.cpp | `5 2` | `10` | 示例 n 为 0 到 10^6，MOD 固定为质数 |
| matrix_power.cpp | `10` | `55` | n>=0，结果模 1000000007 |

在本目录编译一个文件，例如 `g++ -std=c++17 -Wall -Wextra combination.cpp -o combination.exe`，运行后输入示例数据即可。不要把所有 cpp 一起链接，因为它们有各自的 main。

## 学习时重点推导

- 质因数指数为 c 时，为什么约数有 c+1 种选择？为什么分解完后剩余的大于 1 的数一定是质数？
- 分段筛为什么从 max(p², ceil(l/p) × p) 开始标记？试试 [0,2]、[5,5] 和 [49,49]，分别检查 0/1、质数本身和完全平方数。
- 欧拉筛中，i 能否被 p 整除，为什么对应 phi[i]*p 与 phi[i]*(p-1) 两种情况？
- exgcd 给出 a*x+mod*y=1 时，为什么 x 就是逆元？试试 `3 8`：扩欧法有效，但不能直接套用费马小定理。
- 为什么 n>=MOD 时不能使用当前阶乘逆元组合数模板？因为 n! 模 MOD 为 0，没有逆元。
- 为什么快速幂初值是单位矩阵？修改矩阵时，应先写出每一行对应的递推式。

注意：试除法即便使用 ll，也不适合直接处理任意 64 位大素数。扩大模数范围时，还要重新检查乘法是否溢出。
