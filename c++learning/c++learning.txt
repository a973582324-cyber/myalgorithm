内存分区
1.代码区：存放函数体的二进制代码，由操作系统管理
2.全局区：存放全局变量和静态变量以及常量
3.栈区：由编译器自动分配释放，存放函数的参数值，局部变量等
4.堆区：由程序员分配释放，若程序员不释放，程序结束时由操作系统回收

引用引用是C++中的一种类型，它为变量提供了一个别名。
引用必须在定义时进行初始化，并且一旦绑定到一个变量，就不能再绑定到其他变量。引用的语法使用&符号，例如：int& ref = var; 这表示ref是var的一个引用，ref和var指向同一个内存地址，对ref的修改会影响var，
反之亦然。引用在函数参数传递中非常有用，可以避免不必要的复制，提高效率，同时也可以实现函数返回多个值的功能。
在C++11及以后的版本中，可以使用右值引用（rvalue reference）来实现移动语义和完美转发，进一步提高程序的性能和灵活性。
不能返回局部变量的引用，因为局部变量在函数结束后会被销毁，返回它们的引用会导致悬空引用，可能会引发未定义行为。可以使用静态变量或动态内存分配来返回引用，这样它们的生命周期就不会受到函数调用的限制。
引用的本质是一个指针常量，但它的语法更简洁，使用起来更方便。引用在C++中被广泛使用，是C++语言的重要特性之一。
函数的默认参数
函数的默认参数是在函数声明或定义中为参数指定一个默认值，当调用函数时，如果没有提供实参，则使用默认参数的值。默认参数必须从右向左依次指定，不能跳过中间的参数。
默认参数在函数重载中也非常有用，可以减少函数的数量，提高代码的可读性和维护性。
如果函数声明有默认参数，函数实现不能有默认参数，声明和实现只能有一个地方指定默认参数，否则会导致编译错误。默认参数的值必须是常量表达式，不能是变量或函数调用的结果。
void func(int a, int b = 10, int c = 20)//定义函数，b和c有默认值优先使用传入的值
函数重载
函数重载是指在同一个作用域内，允许存在多个函数名相同但参数列表不同的函数。编译器根据函数调用时提供的实参类型和数量来选择匹配的函数版本进行调用。
函数重载可以提高代码的可读性和可维护性，使得函数能够适用于不同类型和数量的参数。函数重载的规则是：
1. 函数名相同，参数列表不同（参数类型、参数数量或参数顺序不同）
2. 函数返回类型不同不能构成函数重载
3. 函数重载不能仅通过参数的默认值来区分
4. 函数重载不能通过参数的类型转换来区分
函数重载的注意事项：
1. 函数重载可能会导致歧义，如果编译器无法确定调用哪个函数版本，会产生编译错误。因此，在设计函数重载时要确保每个函数版本的参数列表足够明确，避免歧义。
2. 函数重载可能会增加编译时间和代码维护的复杂度，因为编译器需要检查每个函数调用的参数类型和数量来确定匹配的函数版本。因此，在使用函数重载时要权衡其带来的便利性和潜在的复杂性。
引用作为函数参数时，函数重载的规则同样适用。引用类型的参数可以参与函数重载，但需要注意以下几点：
1. 引用类型的参数可以是左值引用（T&）或右值引用（T&&）。这两种引用类型在函数重载中被视为不同的参数类型，可以用于区分函数版本。
2. 引用类型的参数可以与非引用类型的参数进行重载。例如，函数可以同时定义一个接受整数参数的版本和一个接受整数引用参数的版本，这样在调用时根据实参的类型来选择合适的函数版本。
左值：指的是具有持久地址的对象，可以在程序中被多次访问和修改。例如，变量、数组元素、函数返回的引用等都是左值。左值可以出现在赋值语句的左侧，也可以作为函数参数传递。
右值：指的是没有持久地址的临时对象，通常是表达式的求值结果。右值不能出现在赋值语句的左侧，但可以作为函数参数传递。

面向对象的三大特性：封装，继承，多态
c++认为万物都皆为对象，对象上有其属性和行为
具有相同性质的对象，都可以抽象为类
封装：将数据和操作数据的函数绑定在一起，形成一个整体，隐藏内部实现细节，只暴露接口给外部使用
继承：子类可以继承父类的属性和行为，并且可以添加自己的属性和行为，形成一个层次结构
多态：同一操作作用于不同的对象，可以有不同的解释和不同的执行结果，分为编译时多态和运行时多态
编译时多态：函数重载和运算符重载
对象的初始化和清理用构造函数和析构函数实现，一个对象或者变量没有初始状态，可能会导致程序出现错误或者不可预期的行为，因此需要通过构造函数来初始化对象的成员变量，确保对象在使用前处于一个有效的状态。同时，析构函数用于在对象生命周期结束时释放资源和执行清理操作，避免内存泄漏和其他资源管理问题。
编译器会自动生成默认的构造函数和析构函数，如果没有显式定义的话，但如果需要自定义构造函数和析构函数，可以根据需要进行定义，以满足特定的初始化和清理需求。
构造函数和析构函数
构造函数：在创建对象时自动调用的特殊成员函数，用于初始化对象的成员变量和分配资源。
析构函数：在对象生命周期结束时自动调用的特殊成员函数，用于释放
资源和执行清理操作。
初始化和清理资源：构造函数负责分配和初始化资源，而析构函数负责释放资源，确保内存和其他资源得到正确管理。
构造函数：类名（）{}
构造函数没有返回值，函数名称和类名相同
构造函数可以有参数，因此可以发生重载
程序在调用对象时会自动调用构造，无需手动调用，且只会被调用一次
析构函数：~类名（）{}
析构函数，没有返回值也不用void
析构函数不可以有参数不可以重载
程序在对象销毁时会自动调用析构，同上。。。
